# Solid JS 2.0

Solid JS 2.0 has completely different mental model than Solid JS 1.x and other frameworks like React. There is always an idiomatic way to do things in Solid JS 2.0. Usually the simplest and obvious way to do something is the right way. Use provided examples and documentation to learn how to use Solid JS 2.0.

Solid JS 2.0 is currently in RC (Release Candidate) phase. Release Candidate means the API is frozen, not that there won't be bugs. If you encounter any issues which docs can not explain, check the open issues on the Solid JS GitHub repository first, and then communicate with the user to highlight the issue, instead of silently ducktaping it.

Solid JS 2.0 reactivity system provides useful DEV diagnostics which can help you catch wrong patterns and bugs with linting and testing tools.
